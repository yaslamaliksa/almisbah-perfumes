# المصباح بلند للعطور — Cinematic Photography V5

## ما الجديد؟
- استبدال مجسمات العطور البرمجية بصور فوتوغرافية مرجعية في الواجهة الرئيسية والمجموعات والمنتجات والعرض السريع.
- حركة سينمائية بطيئة في الصورة الرئيسية، وتكبير عند التفاعل، وتحريك بصري خفيف أثناء التمرير.
- الحفاظ على البحث، التصفية، سلة الاستفسارات، واتساب، ودعم الجوال.
- الصور تُحمّل من Unsplash عبر الإنترنت؛ **ليست مضمنة داخل ملف ZIP**، وقد تتطلب استبدال روابط الصور إن توقفت أو تغيرت.

## مهم جدًا قبل النشر التجاري
الصور **مرجعية فوتوغرافية حقيقية وليست صور منتجات المصباح بلند**. أسماء العطور والأوصاف تجريبية أيضًا. يجب استبدال الصور بصور منتجات المتجر الحقيقية والتأكد من حقوق استخدامها قبل النشر الرسمي. يُفضّل تنزيل الصور المرخصة وتخزينها محليًا بدل الاعتماد على روابط خارجية. بعض روابط الصور غير متحقق منها داخل المتصفح في هذه البيئة.

## التشغيل والنشر
افتح `index.html` في متصفح متصل بالإنترنت. للنشر ارفع جميع الملفات إلى GitHub Pages أو استضافة ثابتة أخرى.
